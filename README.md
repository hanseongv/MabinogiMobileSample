# Mabinogi Mobile Study Project

## Overview

A personal Unity game development project

This project is an independent, unofficial
learning and portfolio project.

## Project Goals

- Study and implement selected gameplay systems.
- Practice scalable Unity architecture.
- Apply professional Git and GitHub workflows.
- Build a playable prototype.

## Tech Stack

- Engine: Unity
- Language: C#
- Version Control: Git / GitHub
- CI/CD: GitHub Actions
